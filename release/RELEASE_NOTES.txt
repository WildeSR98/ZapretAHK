Zapret Manager v2.5.0

🖥 Системный трей
• Иконка в трее — статус службы, текущая стратегия
• Контекстное меню: переключение стратегий, перезапуск/остановка службы
• Трей работает как отдельный процесс — живёт после закрытия консоли
• Автозапуск при старте Windows через Планировщик задач (Настройки → п.6)
• Из трея можно открыть консоль или полностью выйти

🔄 Watchdog + Авторотация стратегий
• Фоновый мониторинг доступности сайтов (интервал настраивается)
• Если сайты недоступны — автоматическое переключение на следующую стратегию из рейтинга
• Рейтинг стратегий строится из результатов тестов
• Кулдаун между ротациями, максимальное число попыток
• Включается в сервисном меню (п.17)

⚡ Speed-тест
• Измерение скорости БЕЗ обхода и С обходом (download/upload/latency)
• Сравнение: показывает реальное влияние DPI bypass на скорость
• Используется Cloudflare CDN (бесплатный, стабильный)
• Сервисное меню п.18

🛠 Редактор стратегий
• Создание новой стратегии с нуля или на базе шаблона
• Редактирование существующих .bat файлов
• Поддержка параметров: dpi-desync, TTL, fooling, TCP/UDP порты
• Сервисное меню п.19

🌐 Определение провайдера + рекомендации
• Автоматическое определение ISP (ip-api.com + ipinfo.io fallback)
• Маппинг ISP→стратегии загружается с GitHub и мержится с локальным
• Кэширование на 24 часа
• Сервисное меню п.20

📋 Управление доменами
• Whitelist (обходить) и Blacklist (не обходить)
• Добавление/удаление доменов через интерактивное меню
• Файлы whitelist-user.txt / blacklist-user.txt
• Сервисное меню п.21

🔌 Выбор сетевого адаптера
• Список всех доступных адаптеров (Ethernet, WiFi, VPN)
• Показывает IP, скорость, статус
• Сохраняет выбор для параметра --iface
• Сервисное меню п.22

📦 Экспорт/Импорт настроек
• Полный экспорт в ZIP: конфиг, профили, пользовательские списки, кастомные стратегии
• Импорт с подтверждением перезаписи конфига
• Включает meta.json с версией и информацией о системе
• Сервисное меню п.23

🏠 Меню «Настройки» в главном меню
• Новый пункт [7] в главном меню
• Объединяет: обновления, игровой фильтр, IPSet, бэкап, профили, автозапуск трея
• Своя нумерация, удобный доступ без перехода в сервисное меню
