# Zapret Manager v2.5.0

## Что нового

### 🖥 Системный трей
Иконка в трее рядом с часами — статус службы, быстрое переключение стратегий, перезапуск. Трей работает как **отдельный процесс** и не закрывается вместе с консолью. Автозапуск при старте Windows через Планировщик задач.

### 🔄 Watchdog + Авторотация
Фоновый мониторинг: если сайты перестали работать — автоматическое переключение на следующую стратегию из рейтинга. Рейтинг строится из результатов тестов.

### ⚡ Speed-тест
Измерение скорости (download/upload/latency) **до и после** включения обхода. Показывает реальное влияние DPI bypass. Cloudflare CDN.

### 🛠 Редактор стратегий
Создание и редактирование .bat файлов прямо из меню: выбор dpi-desync метода, TTL, fooling, портов.

### 🌐 Определение провайдера
Автоматическое определение ISP и рекомендации по стратегиям. Маппинг загружается с GitHub и мержится с локальным.

### 📋 Управление доменами
Whitelist (обходить) и Blacklist (не обходить) — добавление/удаление доменов через меню.

### 🔌 Сетевой адаптер
Выбор NIC для winws — список адаптеров с IP, скоростью, статусом.

### 📦 Экспорт/Импорт настроек
Полный бэкап всех настроек в ZIP и восстановление на другой машине.

### 🏠 Настройки в главном меню
Новый пункт **[7] Настройки** — быстрый доступ к обновлениям, фильтрам, бэкапу, профилям, автозапуску трея.
